Questions

Good to know before you join.

Is Arthic available to use yet?

Arthic is still in development. The website explains the planned platform, and the waitlist is where you can register interest in early access. Practice tools are not live yet.

Which exams is Arthic being built for?

The current focus is MDCAT, ECAT, NUST NET, FAST, LUMS LNAT, CSS and PMS.

How much will it cost?

Access is free during the early-access period. Visit the pricing page for the current plan and any planned pricing after early access.

What happens after I join the waitlist?

You'll receive an email when there's an update about early access for the exam track you selected. Joining the list does not give immediate access to unfinished features.
